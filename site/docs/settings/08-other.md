## 3.3.  Other



## 3.3.1. Download Log


After click download tab item, charger will pack all log file into a compress 
zip file and show dialog which save destination select.

![img_page42_0](/img/manual/img_page42_0.jpeg)

Image 3-18 Download page



## 3.3.2. Login password


After change configuration web page login password, user need to use new 
password to login on next time.

![img_page43_0](/img/manual/img_page43_0.jpeg)

Image 3-19 Configuration login password set page



## 3.3.3. Export Setting


After click Export Setting item, charger will export all configuration value to a 
bin file and show dialog which save destination select.

Export setting file only can be import to same model name charger.

![img_page44_0](/img/manual/img_page44_0.jpeg)

Image 3-20 Export setting page



## 3.3.4. Restart


After click restart item charger will end charging session and reboot controller.

![img_page45_0](/img/manual/img_page45_0.jpeg)

Image 3-21 Restart page
