## 3.5. Account


This page will appear when user account role is admin. 
There are three role configurations: 
⚫ 
Admin:Full configuration function. 
⚫ 
Manager:Network / Backend configuration 、firmware upgrade and log

file download function. 
⚫ 
User:Read only for all configuration item and download log file.

Password must match complexity principle。
