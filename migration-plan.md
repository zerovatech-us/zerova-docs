# Migration Plan: CSU3 Setting Manual → Docusaurus Site

## Overview
Migrate `CSU3 Setting Manual_V0.23_20250930.pdf` (74 pages, EV charger configuration reference) into a Docusaurus static documentation site. Python + PyMuPDF handles PDF extraction; Docusaurus (TypeScript) serves the result.

---

## Stack

| Layer | Choice | Reason |
|---|---|---|
| Static site | Docusaurus (TypeScript) | React-based, great for technical docs, built-in search & versioning |
| PDF extraction | Python + PyMuPDF (`fitz`) | Handles text + images + table detection in one library, no external binaries |
| Python env | venv inside project dir | Per project rule: all dependencies scoped to this directory |

## Extraction Script Key Design

- `page.get_text("text", sort=True)` — `sort=True` preserves natural reading order
- Header/footer stripping — strings repeated across 3+ consecutive pages are removed (page numbers, doc title, version string)
- Inline table detection — `page.find_tables()` now runs on every page (not just the register table). Phantom outer tables (page-border false positives) are filtered two ways: (1) outer bbox contains an inner table's bbox → drop outer; (2) first row has any cell >200 chars → drop that row. Extracted tables are sorted by y-coordinate alongside text and images.
- Text block exclusion — text blocks whose bounding rect intersects a detected table rect are skipped to avoid duplicating cell text as plain text
- Image placement — all content (text, tables, images) unified into a single y-coordinate sorted list per page
- Vector image fallback — **removed**. Pages with only vector drawings (watermarks) are now silently skipped.
- `text_cleanup()` additions — Chinese full-width colon `：` → `:`, fragmented bullet normalization (`-\n  word` → `- word`)
- `heading_detect()` fix — regex updated to `^\d+(\.\d+){0,3}\.?\s+\S.{0,60}$` to match chapter numbers with trailing dots (e.g. `3.1.1. System`)
- Spot-check output — script prints first 200 chars of each section's start page for manual verification before full extraction

## Docusaurus Configuration

### `site/docusaurus.config.ts` key settings
- `routeBasePath: '/'` — docs served at site root (no `/docs/` prefix)
- `blog: false` — no blog
- `title: 'Zerova Chargers Docs'` — site title and browser `<title>` tags

- `themeConfig.navbar.title: 'Zerova Chargers Docs'`
- `themeConfig.navbar.items[0].label: 'Charger Webpage Manual'`

### `site/sidebars.ts`
Uses `autogenerated` type — sidebar order driven by `sidebar_position` in frontmatter and `position` in `_category_.json`.

### Category files

- `site/docs/appendix/_category_.json`: label `"4. Appendix – Modbus Information"`, position 4
