```
    docs/

    docusaurus.config.ts    # routeBasePath: '/', blog: false

```

Sidebar order is driven by `sidebar_position` in each file's frontmatter and `position` in `_category_.json` files. The first doc (`01-connection-setup.md`) carries `slug: /` to serve as the site root.

## Extraction Script Key Behaviors

- `page.get_text("text", sort=True)` preserves natural reading order
- Header/footer stripping: strings repeated across 3+ consecutive pages are removed (page numbers, version string, doc title)
- `find_tables()` runs on every page; phantom outer tables and rows with cells >200 chars are filtered; text blocks overlapping table rects are skipped to avoid duplicate content
- All content (text, tables, images) is sorted by y-coordinate per page
- Vector images (watermarks) are silently skipped; only raster images are extracted

## Known Limitations

- **Empty first table column:** All parameter tables have a blank first column — PDF border-detection artifact, cosmetic only.
- **`05-network.md` boundary bleed:** PDF page 22 contains tail of Charging section before Network begins; re-extraction always reintroduces the leading fragment.
- **Source PDF typos:** Errors like "reievant", "intput vontage", "Telcoom" originate in the PDF itself.
